# Proyecto-final-kodland

## Esta es la idea de mi proyecto:
> Un bot de discord que con la api de gemini conteste preguntas sobre el cambio climatico.
>
> Comandos Interactivos y Dinámicas
>
> - /eco-scan (Asistente de reciclaje): El usuario sube una foto de un residuo (ej. un envase mixto de plástico y cartón). Gemini analiza la imagen y le dice exactamente cómo separarlo y en qué contenedor tirarlo.
> - /mito-verdadero: Genera trivias en el servidor para desmentir mitos comunes sobre el cambio climático.
> - /quiz-climatico [dificultad]: El bot usa Gemini para generar una pregunta de opción múltiple completamente nueva cada vez (evitando bases de datos aburridas). El primero en responder gana puntos.
> - /analiza-foto: Permite subir una foto (de comida, productos, basura) y usa el modelo multimodal de Gemini para analizar su impacto ambiental o cómo reciclarlo.
> - /reto-diario: Cada 24 horas, el bot lanza un micro-reto al servidor (ej. "Toma una ducha de 5 minutos hoy" o "No uses bolsas de plástico"). Los usuarios reaccionan con un ✅ y el bot les da experiencia (XP).
> - /rank y /leaderboard: Un sistema de niveles. Los usuarios empiezan siendo 🌱 Semilla, luego 🌳 Árbol, hasta llegar a 🌍 Guardián Climático. Puedes integrar esto con la API de Discord para asignar roles reales automáticamente.
> - /desmiente [noticia o frase]: Un "detector de Greenwashing y Mitos". El usuario pega una afirmación dudosa ("El cambio climático es un ciclo natural") y Gemini responde con fuentes y datos científicos que lo desmienten de forma amigable.
> - /calcula-huella: Un cuestionario interactivo de 5 preguntas rápidas por chat (transporte, dieta, vivienda). Al final, el bot te da un estimado de tus emisiones anuales, sugiriendo mejoras.
> - /eco-buenas-noticias: El cambio climático genera mucha "eco-ansiedad". Este comando le pide a Gemini que busque o genere un resumen de avances tecnológicos recientes o leyes positivas para el medio ambiente, manteniendo la moral alta en el servidor.
>
> Sistema de Recompensas o Logros
> - Otorga puntos o Ranks climáticos a los usuarios que participan en las trivias o resuelven sus dudas sobre sustentabilidad para fomentar la competencia sana en el servidor.
>
## Tecnologias a utilizar:
> - Discord developer portal
> - API de gemini
